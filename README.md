First, run the development server:

```bash

# or

# or
pnpm dev
# or
```

## Portfolio admin

The owner workbench is available at `/admin`. It publishes the validated content file and managed project images to GitHub; a Vercel project connected to the configured branch rebuilds automatically.

Configure these server-only environment variables locally and in Vercel:

```text
ADMIN_PASSWORD=<strong owner password>
ADMIN_SESSION_SECRET=<random secret of at least 32 characters>
GITHUB_TOKEN=<fine-grained token with Contents read/write access>
GITHUB_OWNER=CodeZobac
GITHUB_REPO=portfolio.chatbot
GITHUB_BRANCH=main
```

Scope the GitHub token only to this repository. Admin-uploaded JPEG, PNG, and WebP images are optimized in the browser and committed under `public/projects/admin/`.
