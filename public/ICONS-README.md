# Icon Files Setup

This directory should contain the following icon files for optimal SEO and app functionality:

## Required Icon Files

1. **favicon.ico** (already exists in app/favicon.ico)
   - 32x32 or 16x16 pixels
   - ICO format

2. **apple-touch-icon.png**
   - 180x180 pixels
   - PNG format
   - Used for iOS home screen icons

3. **android-chrome-192x192.png**
   - 192x192 pixels
   - PNG format
   - Used for Android home screen icons

4. **android-chrome-512x512.png**
   - 512x512 pixels
   - PNG format
   - Used for Android splash screens

5. **og-image.png**
   - 1200x630 pixels
   - PNG or JPG format
   - Used for Open Graph social media previews

## How to Generate Icons

You can use online tools like:
- https://realfavicongenerator.net/
- https://favicon.io/

Or create them manually using design tools like Figma, Photoshop, or GIMP.

## Design Recommendations

- Use a simple, recognizable logo or initials (e.g., "AC" for Afonso Caboz)
- Ensure good contrast for visibility
- Keep the design clean and professional
- Test on both light and dark backgrounds
- Match your brand colors (consider using black background with white/colored text)
